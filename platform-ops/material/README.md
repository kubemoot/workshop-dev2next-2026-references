# platform-ops material

How Kubemoot runs a crew on Kubernetes: crews and agents, models and scheduling, the
signals of a discussion, what a crew's status means, and how to observe it. The
platform-ops crew indexes this folder in the knowledge step, so it can answer
questions about the system it runs on.

These pages are a snapshot of the Kubemoot documentation
(https://github.com/kubemoot/kubemoot, `docs/`), Apache License 2.0, copied here so
the workshop does not depend on where the documentation is published.
