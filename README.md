# Workshop references: Building an Agentic AI System on Kubernetes, Dev2Next 2026

The public companion to the workshop repository. Two things live here because they
must be reachable by URL from inside a cluster, or because they are better kept a step
away from the worksheets:

- `<wheelhouse>/material/`: the knowledge each wheelhouse's crew indexes as a RAGSource.
  Public so that an indexer running in any cluster can clone it without credentials.
- `<wheelhouse>/solution/`: the prose of a reference crew for each wheelhouse: the
  PromptModules and Agents a team writes, finished, in the same shape as the bundle it
  starts from. They are here rather than beside the recipe so that a team does the
  writing before it does the reading. If you are in the workshop, the afternoon is for
  your own version; open these at show and tell.

Wheelhouses: `platform-ops`, `architecture-review`, `pedagogy`, `game-host`. The
recipes, bundles, tools, fitness scenarios, and everything else are in the workshop
repository, which attendees receive access to on the day.

Apache 2.0, like Kubemoot itself.
