# Workshop references: Building an Agentic AI System on Kubernetes, Dev2Next 2026

The public companion to the workshop repository. Two things live here because they
must be reachable by URL from inside a cluster, or because they are better kept a step
away from the worksheets:

- `<topic>/material/`: the knowledge each topic's crew indexes as a RAGSource. Public so
  that an indexer running in any cluster can clone it without credentials.
- `<topic>/solution/`: a reference crew for each topic, the manifests a team writes in
  Stage A of its worksheet, finished. They are here rather than beside the worksheet so
  that a team does the writing before it does the reading. If you are in the workshop,
  the afternoon is for your own version; open these at show and tell.

Topics: `homelab-ops`, `adl-review`, `exam-questions`. The worksheets, tools, fitness
scenarios, and everything else are in the workshop repository, which attendees receive
access to on the day.

Apache 2.0, like Kubemoot itself.
