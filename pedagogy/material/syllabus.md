# Essentials of Computing: syllabus

An introduction to programming with Python, for students who have not programmed
before. Fifteen weeks: thirteen weeks of teaching, a break after week 8, and an exam.
Each week names the textbook chapters (Akuli's Python tutorial, `basics/`) that teach it.

## Week 1: Introduction to programming with Python

Chapters: what-is-programming.md, installing-python.md, getting-started.md,
editor-setup.md.

By the end of the week a student can: say what a program is; run Python interactively
and from a file; use Python as a calculator; recognise an error message and read its
last line.

## Week 2: Variables and expressions

Chapters: variables.md.

By the end of the week a student can: assign a value to a variable and use it; choose
a variable name that follows the rules and says what it holds; evaluate an expression
with arithmetic operators and parentheses; explain what `x = x + 1` does.

## Week 3: Types

Chapters: what-is-true.md, handy-stuff-strings.md (first part).

By the end of the week a student can: name the types int, float, str, and bool and give
an example of each; convert between them with int(), float(), and str(); predict which
values are truthy and which are falsy; explain why "2" + 2 is an error.

## Week 4: Branching

Chapters: if.md.

By the end of the week a student can: write if, elif, and else; combine conditions with
and, or, and not; predict which branch runs for a given input; indent a block correctly.

## Week 5: Loops

Chapters: loops.md.

By the end of the week a student can: write a while loop and a for loop; loop over a
range of numbers; use break and continue; spot a loop that never ends.

## Week 6: Functions

Chapters: using-functions.md, defining-functions.md, docstrings.md.

By the end of the week a student can: call a built-in function; define a function with
parameters and a return value; tell the difference between printing a value and
returning it; write a docstring.

## Week 7: Strings

Chapters: handy-stuff-strings.md.

By the end of the week a student can: index and slice a string; use common string
methods (upper, lower, strip, split, replace, startswith); format a string with an
f-string; explain that strings cannot be changed in place.

## Week 8: Lists and dictionaries

Chapters: lists-and-tuples.md, dicts.md, zip-and-enumerate.md.

By the end of the week a student can: create a list, index and slice it, and change an
item; add and remove items with append, insert, remove, and pop; loop over a list, with
enumerate when the position matters; create a dictionary, look up, add, and change a
value by key; check whether a key is present with in; loop over a dictionary's keys,
values, and items; explain why a list cannot be a dictionary key and a tuple can.

## Break

## Week 9: Classes

Chapters: classes.md.

By the end of the week a student can: define a class with an __init__ method and other
methods; create objects and use their attributes; explain what self refers to.

## Week 10: Files

Chapters: files.md.

By the end of the week a student can: read a text file line by line; write and append to
a file; use with to close a file; explain what happens when the file does not exist.

## Week 11: Exceptions

Chapters: exceptions.md.

By the end of the week a student can: read a traceback; catch an exception with try and
except; raise an exception with a message; choose which exceptions to catch and which
to let through.

## Week 12: Modules

Chapters: modules.md, larger-program.md.

By the end of the week a student can: import a module and use its functions; split a
program into two files; use the random and math modules; plan a program of a hundred
lines before writing it.

## Week 13: Review and exercises

Chapters: all of the above.

By the end of the week a student can: solve a problem that needs a loop, a function, a
list, and a dictionary together; find and fix a bug from its error message.

## Exam

Part 1 is written: reading code and predicting what it prints. Part 2 is programming:
three short problems, one of them using a dictionary.
