# pedagogy material

A fifteen-week introductory Python course: the syllabus below, week by week, with what
a student should be able to do by the end of each week and the textbook chapter that
teaches it. The pedagogy crew indexes this syllabus and the textbook in the knowledge
step, and writes quizzes and exercises at the level of a given week.

The textbook is Akuli's Python tutorial, https://github.com/Akuli/python-tutorial, the
`basics` chapters, licensed under the zlib License (text) and released into the public
domain (code examples). The crew indexes it from that repository; nothing of it is
copied here. The syllabus is written for this workshop, Apache License 2.0.
